# UMCReminder

Веб-приложение для напоминаний по рабочим задачам. 

## Возможности

- Создание задач со сроками их выполнения
- Контроль статуса задач
- Создание шаблонов для регулярных задач
- Работа с десктоп клиентом для регулярных напоминаний
- Просмотр списка активных и завершённых задач

## Запуск

Проект состоит из двух частей: самого веб приложения и десктоп клиента для регулярных напоминаний

### Веб-приложение

Веб-приложение запускается напрямую через WSGI-сервер без использования Docker.

1. Создать и активировать виртуальное окружение:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

2. Скопировать файл `config.example.py` в `config.py` и заполнить параметры подключения к базе данных и почтовому серверу.

3. Выполнить миграции:

```bash
flask db upgrade
```

4. Запустить приложение:

```bash
gunicorn -w 2 -b 127.0.0.1:8010 app:app
```

### Десктоп клиент

1. Меняем значения `API_URL_INFO`, `API_URL_ALERT_WINDOW`, `API_URL_TASKS` в файле `webview_client.py` на свои, с соответствующим именем хоста
2. Генерируем .exe файл для запуска десктоп клиента на нужных компьютерах

```bash
pyinstaller --onefile --noconsole webview_client.py --add-data "s1.wav;."
```
